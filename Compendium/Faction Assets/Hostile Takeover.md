# Hostile Takeover

| Property | Value |

## Description

This asset can seize control of damaged and poorly-controlled [[Assets|assets]]. If a Hostile Takeover does enough damage to destroy an asset, the target is instead reduced to 1 hit point and acquired by the Hostile Takeover's owning faction.
